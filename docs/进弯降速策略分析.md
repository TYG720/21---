# 进弯降速策略分析

## 概述

本车模采用 **连续分级降速策略**，根据摄像头图像中赛道线的弯曲程度实时计算目标速度，实现"弯越急、速度越慢"的平滑减速效果。

**核心思想：** 不依赖单一"是否进弯"的开关量判断，而是通过多维特征量叠加计算出连续的弯道强度等级（`curve_level`），再根据预设的速度曲线进行线性插值降速，最后通过阶梯缓变函数平滑调整速度。

## 核心函数：`Smart_Dream_speed()`

该函数位于 `Motor.c` 第 185~264 行，是速度规划的主入口。在 `Motor_Loop()` 中每帧调用一次。

### 计算流程

```
图像数据 (mid_line, Out_servo)
        │
        ▼
计算 e_far / e_mid / e_near（中线偏移量）
        │
        ▼
计算 bend = e_near - e_far（弯道曲率）
        │
        ▼
计算 turn_abs = |Out_servo - SERVO_CENTER|（舵机转向量）
        │
        ▼
合成 curve_level_raw = |e_mid|×2 + |bend|×2 + turn_abs/12
        │
        ▼
一阶低通滤波得到 curve_level
        │
        ▼
根据 current_step 判断是否为圆环状态
    ├── 是圆环 → 固定速度 RING_SPEED (100)
    └── 普通赛道 → calc_target_speed(curve_level) 获取目标速度
        │
        ▼
ramp_i16 阶梯缓变调整 tar_speed
        │
        ▼
若 curve_level > U_DIFF_START(80)，开启内外轮差速
        │
        ▼
输出 tar_speed_l / tar_speed_r 给 PID 控制器
```

## 弯道强度等级 `curve_level` 的计算

```c
// Motor.c line 196~214
e_far  = (int16)mid_line[30]  - Mid_Col;   // 远处(30行)中线偏移
e_mid  = (int16)mid_line[80]  - Mid_Col;   // 中部(80行)中线偏移
e_near = (int16)mid_line[100] - Mid_Col;   // 近处(100行)中线偏移

bend = e_near - e_far;                      // 弯道曲率

if(Out_servo > SERVO_CENTER)
    turn_abs = Out_servo - SERVO_CENTER;    // 左转量
else
    turn_abs = SERVO_CENTER - Out_servo;    // 右转量

curve_level_raw = abs_i16(e_mid) * 2 + abs_i16(bend) * 2 + turn_abs / 12;

// 一阶低通滤波
curve_filter = curve_filter * 0.75f + curve_level_raw * 0.25f;
curve_level = (uint16)curve_filter;
```

### 三个分量的物理含义

| 分量 | 代码 | 含义 | 权重 |
|------|------|------|------|
| **中线偏移量** | `abs(e_mid) × 2` | 图像中心行(80行)的赛道中线偏离图像中心的程度。数值越大说明车体偏离赛道中心越远，弯道越急 | 高（系数2） |
| **弯道曲率** | `abs(bend) × 2`<br>`bend = e_near - e_far` | 近处(100行)与远处(30行)中线偏移之差。反映赛道在视野内的弯曲程度，差值越大弯越急 | 高（系数2） |
| **舵机转向量** | `turn_abs / 12` | 当前舵机打角的绝对值，表示实际物理转向幅度 | 辅助（系数1/12） |

### 低通滤波

```
curve_filter = curve_filter × 0.75 + curve_level_raw × 0.25
```

为什么需要滤波：防止因图像噪声或单帧抖动导致 `curve_level` 忽大忽小，进而引起速度频繁波动。滤波后速度变化更平滑，车模过弯更稳定。

## 目标速度映射：`calc_target_speed(curve_level)`

```c
// Motor.c line 154~184
static int16 calc_target_speed(uint16 curve_level)
{
    if(curve_level <= CURVE_MIN_LEVEL)      // ≤30
        target = STRAIGHT_SPEED (150);
    else if(curve_level <= CURVE_MID_LEVEL) // 30~105
        target = 150 → 100 (线性插值);
    else if(curve_level <= CURVE_MAX_LEVEL) // 105~200
        target = 100 → 80 (线性插值);
    else                                    // >200
        target = U_CURVE_SPEED (80);
}
```

### 速度分段表

| curve_level 范围 | 赛道类型 | 目标速度 | 说明 |
|-----------------|---------|---------|------|
| 0 ~ 30 | **直道** | **150** (`STRAIGHT_SPEED`) | 不降速 |
| 30 ~ 105 | **普通弯** | **150 → 100**（线性下降） | 缓弯到中等弯 |
| 105 ~ 200 | **大弯 / U型弯** | **100 → 80**（线性下降） | 急弯到U型弯 |
| > 200 | **极限弯道** | **80** (`U_CURVE_SPEED`) | 最低保护速度 |

图示文字描述：

```
速度

150 ┤████████████████████████
    │                        ↘
100 ┤                         ██████████████████
    │                                          ↘
 80 ┤                                           ████████████████████
    └──┬─────┬────────────┬──────────┬──────────┬──→ curve_level
      0     30            105        200
      直道   普通弯         大弯/U弯    极限弯道
```

## 加减速平滑：`ramp_i16`

```c
tar_speed = ramp_i16(tar_speed, target_speed, SPEED_ACC_STEP, SPEED_DEC_STEP);
```

| 参数 | 值 | 含义 |
|------|----|------|
| `SPEED_ACC_STEP` | 1 | 每帧加速增量上限（加速慢） |
| `SPEED_DEC_STEP` | 6 | 每帧减速增量上限（减速快） |

减速比加速快（6 > 1），保证进弯时能快速减速，出弯时缓慢恢复速度，提高过弯稳定性。

## 差速控制（弯道内外轮差速）

当 `curve_level > U_DIFF_START(80)` 时启用差速，使左右轮产生速度差以辅助转向。

```c
// Motor.c line 229~260
diff = tar_speed × DIFF_RATIO × turn_abs / (100 × MAX_TURN);
diff = limit(diff, 0, DIFF_MAX);

左弯: tar_speed_l = tar_speed - diff,  tar_speed_r = tar_speed + diff
右弯: tar_speed_l = tar_speed + diff,  tar_speed_r = tar_speed - diff
```

| 参数 | 值 | 含义 |
|------|----|------|
| `U_DIFF_START` | 80 | 差速启动阈值 |
| `DIFF_RATIO` | 22 | 差速强度比例 |
| `DIFF_MAX` | 22 | 最大差速量 |

特点：
- 弯道强度等级小于80时不差速（避免小弯贴内）
- 差速量正比于舵机转向量 `turn_abs`
- 每个车轮速度最终限制在 50 ~ 160 之间

## 圆环场景特殊处理

当 `current_step`（圆环状态机步数）在 1~10 范围内时，目标速度固定为 `RING_SPEED(100)`，不受 `curve_level` 影响：

```c
if(current_step > 0 && current_step < 11)
{
    target_speed = RING_SPEED;  // 100
}
else
{
    target_speed = calc_target_speed(curve_level);
}
```

原因：圆环是固定几何结构，弯道特征与普通赛道不同，直接用 `curve_level` 计算可能导致速度异常。因此圆环走固定低速策略。

## 旧版降速策略（`Dream_speed`，已弃用）

旧版本仅依赖舵机转向量 `tp_turn` 进行速度计算：

```c
tar_speed = MAX_SPEED - (MAX_SPEED - MIN_SPEED) × tp_turn / MAX_TURN;
```

| 参数 | 值 |
|------|----|
| `MAX_SPEED` | 150 |
| `MIN_SPEED` | 65 |

**缺点：** 仅依据舵机打角，反应滞后（舵机输出是控制结果而非路况特征），且没有滤波和分级，速度波动大。现已弃用，由 `Smart_Dream_speed()` 替代。

## 总结

本降速策略的核心判断逻辑：

1. **不依赖单一信号**，而是融合**中线偏移量 + 弯道曲率 + 舵机转向角**三个维度
2. **连续分级降速**，而不是开关式跳变
3. **一阶低通滤波**消除噪声抖动
4. **阶梯缓变函数**实现平滑加减速（减速快、加速慢）
5. **高弯道强度自动开启差速**辅助过弯
6. **圆环场景走固定低速**，避免误判
