# 第 21 届智能车竞赛：雁过留痕

这是第 21 届全国大学生智能汽车竞赛“雁过留痕”方向的单片机工程代码，基于 `STC32G144K` 控制器和逐飞科技相关库开发。

项目包含赛道巡线、全元素处理、环岛状态机、激光打靶、电机闭环控制、编码器反馈、摄像头图像处理、陀螺仪辅助和 WiFi SPI 调试等功能。

> 说明：本仓库是比赛阶段工程的整理版，参数和硬件连接与原车模相关。它用于学习、复现和二次开发，不保证脱离原车模后可以直接运行。

## 主要功能

- 基于 `MT9V03X` 摄像头的灰度图像采集和巡线。
- 赛道全元素处理，包括普通弯道、十字和环岛等场景。
- 环岛状态机与补线逻辑，核心代码位于 `project/code/Ring.c`。
- 激光目标检测和打靶，核心代码位于 `project/code/laser.c`。
- 左右轮独立闭环控制、编码器反馈和基于 PID 的电机调速。
- 双比例与姿态变化率阻尼相结合的舵机控制，改善高速转向时的振荡和过冲。
- 基于图像中线、弯道变化和舵机转角的动态降速策略。
- `IMU660RA` 姿态解算、航向辅助和陀螺仪零漂抑制。
- 基于相邻像素灰度差比/对比度的边线搜索与动态加权中线拟合。
- WiFi SPI 和逐飞助手图像调试接口。

## 控制与视觉算法

### 双轮闭环与姿态阻尼

左右驱动轮分别使用增量式 PID 控制器，根据目标速度与编码器实际速度计算电机输出，并结合转弯差速、速度斜坡和输出限幅，提高直道运行稳定性和弯道响应速度。控制器保留 P/I/D 参数配置接口，当前比赛参数以 P/PI 调速为主，具体参数位于 `project/code/PID.c`。

舵机控制采用“**双比例 + 姿态变化率阻尼**”结构：视觉中线误差经过基础比例项和误差二次比例项生成转向量，同时引入 IMU660RA Z 轴角速度反馈，通过 `-kg * imu660ra_gyro_z` 对舵机输出进行姿态阻尼补偿。这里使用的是角速度变化率反馈，并非将积分后的 `yaw` 航向角直接作为传统 D 项，主要用于抑制高速转向过程中的振荡和过冲。

### 姿态解算与航向辅助

系统以 5 ms 周期读取 IMU660RA 陀螺仪数据，对 Z 轴角速度进行 100 次静止采样零偏校准，并通过角速度死区、积分和 `-180°` 到 `180°` 的角度归一化得到航向角 `yaw`。其中，`yaw` 主要用于环岛状态机的航向区间判断，Z 轴角速度则用于转向控制中的姿态反馈。经过比赛实车调试，该方案能够有效减小车辆转向过程中的姿态漂移和累计误差。

### 基于差比/对比度的视觉巡线

视觉处理首先根据图像灰度统计动态计算黑白阈值，再利用相邻像素灰度差计算对比度，在赛道图像中搜索左右边线。获得边线后，根据远、中、近多个区域的中线偏差和弯道趋势动态调整行权重，完成中线拟合，并将拟合误差用于舵机控制和弯道降速。核心实现位于 `project/code/image.c`，主流程由 `project/user/main.c` 调用。

## 硬件条件

当前代码默认使用或适配以下硬件，实际连接请以你的车模原理图为准：

- `STC32G144K` 单片机。
- `MT9V03X` 摄像头。
- `IMU660RA` 陀螺仪。
- 带方向增量编码器的左右驱动电机。
- 舵机、激光模块、蜂鸣器和按键/拨码输入。
- WiFi SPI 模块或逐飞助手调试设备。

部分引脚定义集中在 `project/code/Motor.h`、`project/code/Init.h` 以及逐飞库的配置文件中。更换主板、摄像头或电机驱动后，需要先核对引脚和外设接口。

## 软件环境

- Keil C251 或与当前 `STC32G144K` 工程兼容的 C251 工具链。
- Keil 工程文件：`project/mdk/seekfree.uvproj`。
- 工程使用的逐飞科技库已随仓库放在 `libraries/` 目录中。

本环境没有 C251 编译器，因此本次整理没有进行 Keil/C251 编译验证。使用者需要在本地安装相应工具链后自行编译，并根据实际硬件调试参数。

## 使用步骤

1. 克隆或下载本仓库。
2. 使用 Keil 打开 `project/mdk/seekfree.uvproj`。
3. 在 `project/code/Init.h` 中设置本地 WiFi SPI 密码：

   ```c
   #define WIFI_SPI_PASSWORD "YOUR_WIFI_PASSWORD"
   ```

   如果不使用 WiFi SPI 调试，可以按照实际硬件情况关闭对应初始化逻辑。

4. 检查摄像头、编码器、电机、舵机、陀螺仪和激光模块的接线及引脚定义。
5. 根据车模机械结构重新校准 PID、舵机中值、速度参数、阈值和环岛参数。
6. 编译、下载并在实际赛道上逐项调试。
